# The fourth-dimensional hypothesis

Week 11 — current state of the field

---

{/* _class: banner */}

## Leading. Not settled.

This is the framework most current cases get read against informally —
including, off the record, some of this course's own on-campus cases.
That popularity is not the same as proof.

---

## The core claim

A structurally-adjacent higher-dimensional space intersects ordinary
space at specific, unstable points. Most of the corpus's convergent
triggers — thresholds, counts, timing — mark where that intersection is
currently unstable, rather than being independent phenomena.

---

## Held to week 10's standard, not a new one

Same falsifiability test as every framework last week. What would have
to be true for this hypothesis to be wrong? What in the corpus would
count against it?

---

{/* _class: impact */}

# The strongest evidence, and the strongest exception

As much time goes to the corpus cases that resist this reading as to
the ones that fit it.

---

## Dissent, treated as data

A colleague's published disagreement with the hypothesis is read the
same way the hypothesis's own supporting evidence is read — not
dismissed as noise for being a minority position.

---

## Why "most people read it this way" isn't "this is what's happening"

Popularity and correctness are different claims. This course keeps them
visibly separate rather than letting one stand in for the other.

---

{/* _class: quote */}

> Leading is not the same claim as settled.
