## The brief

> Write up the seminar-room and 13-step stairwell cases as a single
> Field Case File the course can add to its running record.

A case file is not a longer log. The log proves you were there and followed
protocol; the file additionally has to state where each case currently sits
in the course's classification scheme (persistent, recurring,
responsive, or dormant) and defend that call against specific entries in the
log — not against how the case felt to observe.

## What you submit

One document covering both cases, structured so a marker can find, for each
case: the log excerpts that support your classification, an explicit note
of anywhere the buddy system or disengagement rule was invoked, and your
classification with its justification. Where you cite unavailable
precedent — Incident SU-6-04<span class="stamp stamp--status">cited, not observed</span>,
for instance — keep it visibly separate from what you personally logged;
a marker is checking that distinction, not just the citation's presence.

The weighted criteria above split roughly as you'd expect: documentation
rigor asks whether a second observer could reconstruct what you saw from
what you wrote; safety-protocol adherence asks whether the field rules from
week 4 were visibly followed, not just claimed; analytical quality asks
whether your classification actually follows from the log, using the
vocabulary from week 2.
